# 宿舍安全与消防管理规定

本规定适用于 SEA 东南亚、EU 欧洲、ME 中东、NEA 东北亚四个海外区域全部企业宿舍的在住员工、访客与公寓管理人员。宿舍安全实行"谁在住、谁负责，谁管理、谁检查"的原则，区域管理员为所属区域宿舍安全第一责任人。

## 一、电器使用限制

宿舍用电安全是消防管理的首要环节，须遵守以下限制：

1. 严禁使用电炉、电磁炉、电热毯、电暖器、"热得快"、电饭锅等大功率发热电器，单个插座负载不得超过 1500 瓦。
2. 严禁私拉乱接电线、串接多个插线板、使用无 3C 或当地安全认证的转换插头与充电器。
3. 严禁在床头、被褥、窗帘附近充电，充电设备不得彻夜无人看管；离开房间须拔除充电器。
4. 使用吹风机、卷发棒等合规电器时，单次连续使用不得超过 15 分钟，使用后须待完全冷却再收纳。
5. 发现插座发烫、焦糊味、跳闸等异常，须立即断电并报告区域管理员，不得自行拆修。
6. 因违规使用电器导致跳闸、设备损坏或火情的，责任人承担全部赔偿与相应责任。

## 二、禁止明火与吸烟

1. 宿舍楼内全域禁止明火，包括点蜡烛、焚香、烧纸、使用酒精炉与炭火烧烤。
2. 室内、楼道、电梯、阳台、公共厨房以外的区域全面禁烟。吸烟须前往公寓指定的室外吸烟点。
3. 严禁卧床吸烟，严禁将未熄灭的烟头丢入垃圾桶或窗外。
4. 电子烟适用与香烟相同的禁烟区域规定。
5. 违反禁烟规定的，首次予以书面警告并记录在案；第二次起每次计收所在区域等值 100 美元的清洁与安全违约金，并通报所属部门。
6. 因吸烟触发烟感报警或造成火情的，由责任人承担全部处置费用，并视情节暂停其宿舍使用资格。

## 三、消防通道与灭火器位置

1. 每层楼的安全出口、疏散通道与消防楼梯须保持 24 小时畅通，严禁堆放行李、纸箱、自行车或其他杂物。
2. 灭火器通常配置于每层电梯厅、楼梯口与公共厨房入口处，消防栓箱位于走廊两端，具体位置以入住时发放的《房间消防疏散图》为准。
3. 员工办理入住后须自行熟悉本房间最近的两条疏散路线、灭火器与消防栓位置，区域管理员在新入住 3 日内完成一次口头提示。
4. 灭火器压力表指针须处于绿色区域，铅封完好。发现压力不足、过期或缺失的，立即报告区域管理员。
5. 严禁遮挡、挪用、损坏消防设施，严禁在消防通道内为电动车或电池充电。
6. 严禁在疏散楼梯间堆放物品或锁闭安全出口；防火门须保持常闭但不锁死。

## 四、燃气与用电安全

1. 使用燃气的公共厨房，用火期间人员不得离开；使用完毕须关闭灶前阀与燃气总阀。
2. 发现燃气异味时，严禁开关电器、严禁使用明火与手机，应立即开窗通风、关闭阀门，撤离至室外安全区域后拨打燃气抢修电话与区域管理员电话。
3. 公寓燃气管道、热水器由公寓管理方定期检修，员工不得私自拆改、迁移或加装。
4. 长时间外出（超过 3 日）前，须关闭房间内非必要电器电源、水阀与燃气阀门。
5. 雷雨天气应拔除电视、电脑等设备电源与网线，避免雷击损坏与电气火灾。
6. 电气火灾须先断电再灭火，严禁在未断电情况下用水扑救。

## 五、陌生人进入规定

1. 宿舍实行门禁管理，员工须刷卡进入，严禁尾随他人进入楼栋，严禁为陌生人开门。
2. 访客须在公寓前台或门卫处登记有效证件，由被访员工全程陪同，访客不得单独停留于房间与公共区域。
3. 访客时间限定为每日 09:00 至 21:00，不得留宿。特殊情况须提前向区域管理员报备并获批准。
4. 严禁将门禁卡、钥匙转借他人，严禁带非本公司人员入住、留宿或使用宿舍设施。
5. 严禁在宿舍内从事经营性活动、聚众赌博、酗酒滋事或其他违反当地法律的活动。
6. 发现可疑人员、撬门痕迹或异常情况，应立即联系公寓前台、区域管理员或当地警方，不得自行处置冲突。

## 六、财物保管

1. 员工应妥善保管护照、现金、电脑等贵重物品，离开房间须锁门关窗，低层房间不宜开窗存放贵重物品。
2. 公寓不承担个人财物的保管责任。建议贵重物品存入房间保险箱或随身携带。
3. 大额现金与重要证件建议分处存放，并留存复印件或电子备份。
4. 发生盗窃、遗失的，须在 24 小时内报告区域管理员，并向当地警方报案取得报案回执，用于后续保险与责任认定。
5. 员工之间不得私自借贷大额钱款，因个人借贷引发的纠纷由当事人自行承担。
6. 退房时须清点个人物品，遗留物品按《入住与退房办理规范》代管处理。

## 七、突发事件应急联系流程

发生火情、燃气泄漏、治安事件、人员伤病等突发事件时，按以下顺序处置：

1. 步骤 1：确保自身安全，立即撤离至安全区域，不贪恋财物、不乘坐电梯。
2. 步骤 2：拨打当地紧急电话。新加坡警察 999、救护 995；德国通用紧急电话 112；阿联酋警察 999、救护 998；日本警察 110、救护与火警 119。
3. 步骤 3：同步联系区域管理员与公寓前台，报告位置、事件类型与人员情况。
4. 步骤 4：区域管理员在 30 分钟内上报总管理员，并配合当地应急部门处置、做好员工安置与家属通报。
5. 步骤 5：事件处置结束后 3 个工作日内提交书面情况报告，纳入宿舍安全档案。

## 八、违规处理

违反本规定的，视情节给予以下处理：

1. 口头提醒与书面警告，适用于首次轻微违规，如临时占用消防通道、未按规定关闭燃气阀门。
2. 违约金，适用于禁烟违规、私自使用大功率电器、私自留宿访客等，金额为所在区域等值 100 美元，从押金或薪酬中扣除。
3. 暂停宿舍使用资格，适用于造成火情隐患、损坏消防设施、逾期未退房等，暂停期限 1 至 6 个月。
4. 取消宿舍使用资格并通报所属部门，适用于引发火情、盗窃、暴力冲突或违反当地法律被处罚的严重情形。
5. 涉及违法犯罪的，移交当地执法机关处理，公司配合调查并依据劳动合同与员工手册另行处理。
