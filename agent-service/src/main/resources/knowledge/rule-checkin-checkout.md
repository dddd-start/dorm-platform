# 入住与退房办理规范

本规范明确海外企业宿舍的入住办理、钥匙与门禁卡管理、退房检查、提前退房、延迟退房与逾期后果。员工须在入住订单（ORDER）载明的日期区间内办理入住与退房，入住申请状态随办理动作依次流转为 CHECKED_IN 已入住与 CHECKED_OUT 已退房。

## 一、入住办理时间窗口

入住办理时间为入住日当天 14:00 后。具体口径如下：

1. 最早可入住时间为入住日当天 14:00，早于 14:00 到达的员工可在公寓公共休息区等候，或联系区域管理员协调临时寄存行李。
2. 最晚入住时间为入住日次日 23:59。超过该时点仍未办理入住的，入住申请自动失效，状态置为 EXPIRED 已失效，床位即时释放。
3. 因航班延误、签证延误等不可抗力无法按期到达的，须在入住日次日 23:59 前联系区域管理员申请延期，经同意后可顺延最多 48 小时，每单仅限一次。
4. 办理入住须由员工本人到场，不得由同事代办。确因特殊原因无法到场的，须提前向区域管理员书面说明并获批准。
5. 入住订单状态为 RESERVED 已预订时方可办理入住；订单已取消（CANCELLED）或申请已失效（EXPIRED）的，不得办理入住。

## 二、办理入住需要出示的证件与材料

办理入住时，员工须向公寓前台或区域管理员出示以下材料，缺一不可：

1. 本人有效护照或身份证件原件，用于核验身份与登记。
2. 系统生成的入住订单号（ORDER 编号）或二维码，用于核销订单。
3. 出差单号，便于与出差行程交叉核验。
4. 目的地国要求的居留登记材料，如德国的 Anmeldung 登记表、日本的在留卡、阿联酋的入境签证页等，按属地须知要求准备。
5. 联系电话与紧急联系人信息，用于突发情况联络。

办理完成后，系统将入住申请状态置为 CHECKED_IN 已入住，订单状态同步置为 CHECKED_IN 已入住，床位状态由 LOCKED 已锁定转为 OCCUPIED 已占用。

## 三、钥匙与门禁卡管理

钥匙与门禁卡管理遵循"一床一卡、离宿归还"原则：

1. 每名入住员工仅发放一张门禁卡与一把房间钥匙（或一体式门禁卡），不得转借、复制或私自配制。
2. 入住时领取需在《宿舍物品签收单》上签字确认，退房时归还并核销。
3. 门禁卡遗失或损坏的，须在 24 小时内向区域管理员报失，补办工本费为所在区域等值 20 美元，费用由员工个人承担。
4. 门禁卡不得用于开启非本人分配房间的门禁，不得带无权限人员进入公寓楼层。
5. 退房时未归还门禁卡或钥匙的，区域管理员有权从押金或薪酬中扣除补办费用；连续两次遗失的，将在宿舍系统中记录违规。
6. 门禁记录保留 180 天，用于安全审计与纠纷处理。私自复制、外借门禁卡的，按违规处理并暂停其宿舍使用资格。

## 四、退房时间与检查项目

退房时间为退房日当天 12:00 前。退房检查项目包括：

1. 房间与床位清洁状况，垃圾是否清空，个人物品是否全部带走。
2. 家具、电器、灯具、卫浴设施是否完好，有无损坏或缺失。
3. 床品、毛巾等布草是否按入住时数量归还，有无污损。
4. 门禁卡、钥匙、遥控器等配件是否齐全归还。
5. 冰箱内个人食品是否清空，公共区域是否有遗留物品。
6. 水电、空调是否关闭，窗户是否关好。

检查无误后，区域管理员在系统中执行退房确认，入住申请状态置为 CHECKED_OUT 已退房，订单状态同步置为 CHECKED_OUT 已退房，床位状态由 OCCUPIED 转为 AVAILABLE 可分配。

## 五、提前退房与延迟退房

提前退房指实际退房日期早于订单载明的退房日期。员工须提前至少 1 个工作日联系区域管理员提出退房申请，经确认后办理退房，剩余晚数的费用不再计收；已发生的费用按实际入住晚数结算。提前退房后原床位立即释放，可供其他待审批申请分配。

延迟退房指实际退房日期晚于订单载明的退房日期。处理规则如下：

1. 员工须在原退房日前至少 3 个工作日提交续住申请，说明延期原因与新退房日期。
2. 续住须经区域管理员审批，并确认该床位在延长期内未被其他订单锁定。
3. 延长后总入住晚数不得超过 90 晚；超出部分须拆分申请或按长住特殊流程报总管理员审批。
4. 若床位已被后续订单预定，区域管理员应协调换房或换公寓，不得强行占用。
5. 未申请而滞留的，按逾期未退房处理。

## 六、逾期未退房的后果

逾期未退房指员工在退房日 12:00 后仍占用床位且未获批准延期。处理如下：

1. 退房日 12:00 起，区域管理员发出第一次书面提醒；18:00 前仍未搬离的发出第二次提醒并通知其部门负责人。
2. 逾期 24 小时内未搬离的，自逾期首日 12:00 起按该房间挂牌价的 2 倍计收占用费，费用由员工个人承担，不得报销。
3. 逾期超过 72 小时的，区域管理员有权在见证人在场的情况下清点并封存个人物品，代管 30 日；代管期间产生的仓储费用由员工承担。
4. 逾期记录计入宿舍信用档案，同一自然年度内累计两次逾期的，暂停其 6 个月宿舍申请资格。
5. 逾期期间造成的设施损坏或物品遗失，由员工按价赔偿。

## 七、床位释放的时点

床位释放在以下四个时点之一发生，由系统自动执行，任何人不得手工阻止：

1. 员工正常办理退房并经区域管理员确认后，床位立即释放。
2. 入住申请被驳回（REJECTED）或被申请人主动取消（CANCELLED）时，若已锁定床位则同步释放。
3. 审批通过后超过入住日次日 23:59 仍未入住，申请置为 EXPIRED 已失效，床位自动释放。
4. 员工提前退房经确认后，床位在原定退房日之前提前释放。

床位释放后状态回到 AVAILABLE 可分配，区域管理员可立即将其分配给其他待审批的入住申请。释放记录保留在系统中，可用于房源周转率统计与审计追溯。
