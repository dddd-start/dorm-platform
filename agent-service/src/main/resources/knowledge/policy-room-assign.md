# 房间分配原则与房型标准

本规定明确海外企业宿舍的房间分配原则、房型匹配标准、性别限制、床位锁定与满员处理规则。区域管理员在审批入住申请时，必须同时完成分房与床位绑定，分房结果直接写入入住订单（ORDER）。

## 一、房型标准与容量口径

宿舍房型共四类，其容量（床位数）由房型唯一决定：

1. SINGLE 单人间，容量 1 床，独立卫浴，适合单人长住与高职级出差。
2. DOUBLE 双人间，容量 2 床，部分房型共享卫浴，适合同部门同事结伴出差。
3. TRIPLE 三人间，容量 3 床，须限定性别，演示数据中设为男（MALE），仅限同性别员工入住。
4. QUAD 四人间，容量 4 床，须限定性别，演示数据中设为男（MALE），单位床位成本最低。

房型容量是硬约束，任何情况下不得超员分配。房间状态为 OPEN 可分配、CLOSED 已关闭、MAINTENANCE 维修中；仅 OPEN 状态的房间可参与床位分配，CLOSED 与 MAINTENANCE 房间的已有订单须由区域管理员改派至同区域其他公寓。

## 二、按职级与出差时长匹配房型

区域管理员在分房时应同时考虑职级与出差时长两个维度，基本原则如下：

1. 出差 1 至 7 晚的短差：优先分配 DOUBLE 或 TRIPLE/QUAD 多人间，以提升房源周转效率；总监及以上职级可分配 SINGLE。
2. 出差 8 至 30 晚的中期出差：部门经理及以上可分配 SINGLE 或 DOUBLE；普通员工优先分配 DOUBLE，房源紧张时可分配多人间。
3. 出差 30 晚以上的长住：优先分配 SINGLE，以保障长期休息质量与工作产出；SINGLE 不足时可分配 DOUBLE 并尽量安排同项目同事同住。
4. 同一团队、同一项目、出行日期高度重合的员工，应优先安排在同一公寓，减少通勤时间与交通成本。
5. 高职级员工不得挤占已由长住员工锁定的 SINGLE 房源；确需调整的，须报总管理员备案。

分房结果须在入住订单中体现房间号、床位号、公寓名称与地址，申请人可在系统中实时查看。员工对分房结果有异议的，可向区域管理员提出一次调剂申请，调剂不得跨越区域。

## 三、男女不得混住同一间多人间

性别隔离是宿舍分配的强制红线：

1. DOUBLE、TRIPLE、QUAD 等多床房间，同一房间内的全部在住员工必须为同一性别，任何情况下不得安排男女混住。
2. 房间的 gender_limit 字段用于标记性别限制。设置为 MALE 的房间仅可分配给男性员工，设置为 FEMALE 的房间仅可分配给女性员工，设置为 ANY 的房间可在整间为空时按首位入住人性别动态锁定。
3. 首位入住人性别将决定 ANY 房间的性别属性；该房间在全部床位释放前，不得分配给其他性别员工。
4. 因性别限制导致无法分配时，区域管理员应改派至同区域其他公寓的同性别房间，不得以"临时同住"为由突破性别隔离。
5. 家属随行、夫妻同住等特殊情形不属于多人间混住范畴，须走专门的单间审批流程，不得占用多人间床位。

## 四、床位锁定规则

床位锁定采用"审批即锁定"原则：

1. 区域管理员审批通过入住申请的同时，系统即锁定对应床位，床位状态由 AVAILABLE 可分配转为 LOCKED 已锁定，并写入入住订单。
2. 床位锁定自审批通过时刻起生效，持续至员工办理入住（转为 OCCUPIED 已占用）或申请失效/取消（转为 AVAILABLE）。
3. 同一床位在同一日期区间内不得被重复锁定。系统在分房时强制校验日期重叠，重叠锁定会被拒绝并提示冲突订单号。
4. 已锁定但未入住的床位，在申请失效（EXPIRED）后自动释放；区域管理员也可在员工确认取消行程后手工释放。
5. 员工不得自行调换床位、不得私自占用未分配床位。发现私自占用的，区域管理员有权要求其立即搬离，并按《宿舍安全与消防管理规定》记录违规。

## 五、房间满员时的处理

当目标公寓的目标房型全部满员时，区域管理员按以下优先顺序处理：

1. 优先在同区域其他公寓调剂同房型床位，并在审批意见中说明调剂原因与新公寓信息。
2. 同房型无余量时，可降级分配更高容量房型（如由 DOUBLE 调剂至 TRIPLE/QUAD），但须保持性别一致。
3. 降级分配仍需补差的，按《宿舍费用与报销标准》中的超标审批条款执行。
4. 区域全境无可用床位时，区域管理员应在 24 小时内答复申请人，说明可选的替代入住日期区间，或建议改住协议酒店；协议酒店费用按差旅制度另行报销，不占用宿舍额度。
5. 严禁为满足申请而超员分配、临时加床或占用公共区域（客厅、储物间）安置人员。

## 六、优先满足长住与跨区域紧急出差

在房源供不应求时，床位分配遵循以下优先级排序，由区域管理员在审批时执行并留痕：

1. 第一优先级：经总管理员备案的长住员工续住，以及因航班取消、签证延误等突发情况滞留的紧急出差员工。
2. 第二优先级：跨区域紧急出差，即由其他区域临时派往本区域、且出差单标注"紧急"的员工。
3. 第三优先级：出差 8 晚以上的中期出差员工。
4. 第四优先级：1 至 7 晚的常规短差员工。

同一优先级内按入住申请提交时间先到先得。区域管理员调整优先级顺序的，须在审批意见中写明理由，总管理员有权对分房结果进行抽查与纠正。涉及跨区域调剂的，由总管理员统一协调各区域管理员，避免区域间重复占用。
