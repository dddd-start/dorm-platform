# 德国属地须知

本须知面向入住法兰克福会展公寓、慕尼黑公园公寓及其他 EU 欧洲区域宿舍的员工，介绍申根签证、居留登记、公共交通、气候、水电、垃圾分类、紧急联络与生活配套等信息。EU 区域覆盖德国、荷兰、法国、波兰，本须知以德国为主要说明对象。

## 一、申根签证与居留登记（Anmeldung）

1. 赴德出差须持有效护照（剩余有效期不少于 6 个月）与申根短期商务签证（C 类，通常允许 90 天内停留），请提前至少 15 个工作日通过公司行政渠道预约递交。
2. 申根签证须提供行程单、机票预订单、住宿证明、商务邀请函、境外医疗保险（保额不低于 3 万欧元）与财力证明。宿舍地址可作住宿证明：法兰克福会展公寓为 Ludwig-Erhard-Anlage 1, 60327 Frankfurt；慕尼黑公园公寓为 Arnulfstrasse 12, 80335 München。
3. 停留超过 90 天或计划长期驻外的，须办理德国长期签证与居留许可，并由公司协助办理。
4. 在德国境内停留并租住房屋的，须在入住后 14 日内到当地市政厅（Bürgeramt）完成居住登记（Anmeldung），取得登记证明（Meldebescheinigung）。该证明用于开银行账户、办网络与续签，务必妥善保管。
5. 完成登记后如变更住址，须在搬迁后 14 日内办理改址登记（Ummeldung）。
6. 宿舍由公司统一安排的，登记通常由公司行政协助办理，员工须按要求提供护照、签证与入住确认函。

## 二、公共交通与月票

1. 德国城市公共交通由地铁（U-Bahn）、市域快轨（S-Bahn）、有轨电车、公交构成，法兰克福与慕尼黑网络密集，通勤便捷。
2. 车票按区域（Zone）计价，单程票约 3.0 至 4.0 欧元，短途票（Kurzstrecke）约 2.0 欧元。
3. 出差 1 周以上建议购买周票（Wochenkarte）或月票（Monatskarte）。法兰克福市内月票约 90 至 110 欧元；慕尼黑市内月票（IsarCard）约 60 至 100 欧元，具体以当地交通联盟（RMV / MVV）公布价格为准。
4. 也可购买德国全国通用的 Deutschland-Ticket，月费约 58 欧元，可乘坐全德范围内区域交通（不含 ICE/IC 高铁）。
5. 德国公共交通采用信任制，无闸机，但查票频繁。无票乘车（Schwarzfahren）罚款 60 欧元起，并记录在案，务必自觉购票并保留车票至出站。
6. 长途出行可购买德铁（DB）火车票，提前 1 至 2 周预订可享 Sparpreis 优惠价，ICE 高铁较贵，行程规划建议优先使用区域列车。

## 三、气候与衣物建议

1. 德国属温带海洋性向大陆性过渡气候，四季分明。冬季（12 月至 2 月）气温常在零下 5 至 5 摄氏度，夏季（6 月至 8 月）气温约 18 至 30 摄氏度。
2. 11 月至次年 3 月阴雨较多且日照短，须备防水外套、保暖内层与保暖鞋。
3. 夏季昼夜温差大，早晚偏凉，建议携带薄外套与长裤。
4. 德国室内普遍有暖气，冬季室内温暖，建议采用"洋葱式穿衣法"，方便穿脱。
5. 商务场合着装偏正式，建议携带 1 至 2 套正装与一双皮鞋。
6. 建议携带雨伞或冲锋衣，全年降水分布均匀。

## 四、电压与插座

1. 德国民用电压为 230V，频率 50Hz，插座为欧标 C 型（两圆孔）与 F 型（两圆孔带接地夹）。
2. 中国电器（220V）在当地可直接使用，插头形状不同，须携带欧标转换插头。
3. 建议携带多口 USB 充电器与一个欧标插线板，注意总功率不超过 1500 瓦，避免使用大功率发热电器。
4. 德国插座多为圆孔内凹式，部分粗插头可能插不进，建议选用细杆转换头。
5. 雷雨天气建议拔除精密电子设备电源。宿舍已提供基本插座，如需额外插线板可向区域管理员申请。

## 五、周日商店关门

1. 德国《商店营业时间法》规定，周日与法定节假日商店原则上不营业，超市、商场、药妆店与多数店铺均闭店。
2. 周六营业时间通常至 20:00，部分小店 16:00 即关门，建议周六完成一周采购。
3. 周日仍营业的场所包括火车站与加油站内的超市（如 REWE To Go、Edeka）、部分面包房（上午）、餐厅、咖啡馆与博物馆。
4. 药店（Apotheke）周日轮流值班（Notdienst），可在门口查询当日值班药店或拨打当地值班查询电话。
5. 周日禁止使用洗衣机、吸尘器、电钻等产生噪音的设备，公寓内须保持安静。
6. 建议在入住当周即规划采购节奏，避免周日断粮。

## 六、垃圾分类

德国垃圾分类执行严格，错误投放可能被拒收或罚款。主要分类如下：

1. 生物垃圾（Bioabfall）：厨余、果蔬残渣、花园废物，投入棕色桶。
2. 包装垃圾（Verpackung / Gelber Sack）：塑料包装、金属罐、复合包装，投入黄色桶或黄色袋。
3. 纸类（Papier）：纸箱、报纸、杂志、信封，投入蓝色桶。纸箱须压扁。
4. 玻璃（Glass）：按颜色分白、绿、棕三类投入街边玻璃回收箱（Altglascontainer），投放在 08:00 至 20:00 之间，周日禁止投放。
5. 剩余垃圾（Restmüll）：无法回收的垃圾，投入灰色或黑色桶。
6. 押金瓶（Pfand）：塑料瓶与易拉罐标有 Pfand 标志的，可在超市自动回收机退回，每个 0.25 欧元。
7. 大件垃圾、电子垃圾与有害垃圾须预约回收或送至回收中心（Wertstoffhof），不得随意丢弃在楼道或街边。

## 七、紧急电话

1. 欧盟通用紧急电话：112（警察、消防、救护通用，免费，可英语通话）。
2. 德国警察非紧急电话：110。
3. 医疗急救值班医生（Ärztlicher Bereitschaftsdienst）：116117。
4. 中国驻德国大使馆领事保护与协助电话：+49 30 27588 555。
5. 公寓前台：法兰克福会展公寓 +49 69 7700 1234；慕尼黑公园公寓 +49 89 5500 2345。

遇到危及人身安全的情况先拨打 112，随后联系 EU 区域管理员报备。

## 八、租房登记与门牌

1. 德国地址格式为"街道名 + 门牌号，邮编 + 城市"，如 Arnulfstrasse 12, 80335 München。门牌号可能带 a、b 后缀，注意区分。
2. 每栋楼入口处通常有住户门牌（Klingelschild）与信箱标签，需按公寓管理方要求填写本人姓名。
3. 完成 Anmeldung 后，市政厅会提供登记证明，办理银行开户、网络、手机合同均须出示。
4. 德国信件投递为纸质信箱，重要信件（如税号、保险、账单）须定期查看信箱，长期外出请委托他人代收或设置转寄。
5. 退房时须办理注销登记（Abmeldung），并向公寓方归还钥匙、完成验收（Übergabeprotokoll）。

## 九、周边生活配套

1. 超市：法兰克福会展公寓周边有 REWE、Aldi、Lidl 与 dm 日用品店；慕尼黑公园公寓周边有 Edeka、Penny 与 Müller。
2. 诊所：一般疾病可预约全科医生（Allgemeinarzt），急诊前往医院（Klinik）急诊部或拨打 116117。就医费用凭单据申请商旅保险报销。
3. 中餐馆与亚洲超市：法兰克福火车站周边与慕尼黑中央火车站附近有较多中餐馆与亚洲超市（如 Go Asia），可采购调味品与中式食材。
4. 银行与取现：Sparkasse、Deutsche Bank、Commerzbank 网点较多，ATM 支持银联取现的机器有限，建议自备少量欧元现金（德国仍普遍使用现金）。
5. 通信：可在超市或运营商门店购买 Vodafone、O2、Telekom 预付费卡，约 10 至 20 欧元，需实名激活。
6. 购物与生活：商场营业时间通常为 10:00 至 20:00，周六至 20:00，周日休息。
